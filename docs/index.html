Mermaid diagrams, written as text

A Confluence Cloud macro that turns a few lines of Mermaid into a diagram, with a preview that redraws as you type.

What it does

Mermaid lets you write a diagram the way you write a sentence. Four lines of text become a flowchart, and you edit the text rather than drag the shapes. This macro renders it inside Confluence.

Insert the macro, type or paste your source, and the preview draws beside you. If the syntax breaks you get the parser's own message and the line number, before you save rather than after.

Why another one

Most Mermaid macros for Confluence point at a code block somewhere on the page and track it by position. Add a paragraph above it and the diagram detaches or breaks. That is the most common complaint against the incumbents.

This one stores the diagram source inside the macro. Nothing is read from the page, so nothing on the page can break it, including when the page is embedded through the Include Page macro.

Supported diagrams

Flowchart, sequence, class, state, entity relationship, Gantt, pie, git graph, mindmap, user journey, quadrant, timeline, block, C4, requirement, sankey, XY chart and more. Ten starter diagrams are built in.

Privacy in one line

Your diagram text stays in Confluence and is drawn in your own browser. Nothing reaches a server we run, because we do not run one. See the privacy policy.
